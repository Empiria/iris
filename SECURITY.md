# Security policy

## Reporting a vulnerability

Please report security problems privately. Use GitHub's private vulnerability
reporting: open the **Security** tab of [Empiria/iris](https://github.com/Empiria/iris),
choose **Report a vulnerability**, and describe the problem, the steps to
reproduce it and the version or commit you tested.

Please don't open a public issue or pull request for a vulnerability.

You'll get an acknowledgement and then updates in the advisory thread. Once a
fix is released we're happy to credit you in the advisory if you'd like.

## Scope

This repository holds Iris itself: the Anvil app, its server code and its
tooling. Problems in [VDO.Ninja](https://vdo.ninja) or in the Anvil platform
should be reported to those projects.

## Supported versions

Iris is deployed from `main`. Fixes land there.
